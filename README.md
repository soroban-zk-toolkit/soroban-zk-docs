# soroban-zk-docs

Documentation site for the Soroban ZK Toolkit.

The site is built with Docusaurus and currently documents the proof lifecycle,
trusted setup, snarkjs migration, code playground, troubleshooting, and
community resources. The material describes development-stage ZK components;
it is not a security audit and should not be treated as production-readiness
evidence for the companion contracts, circuits, or SDK.

## Local development

```bash
npm install
npm start
```

Build the static site with:

```bash
npm run build
```

See `CONTRIBUTING.md` for documentation conventions and review expectations.
